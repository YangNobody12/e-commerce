🎬 บทพูดและสคริปต์สาธิตระบบ (Live Demo Script)

โครงการ: ระบบร้านค้าออนไลน์ (E-Commerce Web Application) | เวลาสาธิต: 5 - 7 นาที

คำแนะนำ: ซ้อมพูดตามคิวเวลาและขั้นตอนการกดบนหน้าจอ โดยเตรียมเปิดบราวเซอร์ 2 หน้าต่าง (หน้าต่างปกติ = Admin, หน้าต่าง Incognito = User)
นาทีที่ 0:00 - 1:00
1. บทนำและภาพรวมโปรเจกต์ (ผู้พูด: หยาง)

การกระทำ: ยืนหน้าชั้นเรียน เปิดหน้าแรกเว็บไซต์ http://127.0.0.1:8000

"กราบเรียนอาจารย์และสวัสดีเพื่อนๆ ทุกคนครับ วันนี้กลุ่มของเราขออนุญาตสาธิตการทำงานจริงของ 'ระบบร้านค้าออนไลน์ E-Commerce' ซึ่งพวกเราได้ร่วมกันพัฒนาขึ้นด้วย Laravel 11 และ Bootstrap 5 โดยแบ่งงานกันเป็น 5 บทบาทอย่างชัดเจน และทำงานร่วมกันผ่าน Git Branching ครับ ในลำดับแรกขอส่งต่อให้เพื่อนพลับเพื่อสาธิตฝั่งหน้าร้านครับ"
นาทีที่ 1:00 - 2:30
2. การเลือกชมสินค้าและค้นหา (ผู้พูด: พลับ)

การกระทำ: ชี้ให้เห็นหน้าแรก แบนเนอร์ หมวดหมู่ และคลิกเมนู "สินค้า" (/shop) ลองพิมพ์ค้นหา เสื้อ กรองหมวดหมู่ และกรองราคา จากนั้นคลิกดูรายละเอียดสินค้า

"ในส่วนของหน้าร้านค้า เราได้เชื่อมต่อกับฐานข้อมูลจริง รองรับการค้นหา กรองหมวดหมู่ และกรองช่วงราคาได้อย่างแม่นยำ พร้อมทั้งมีหน้ารายละเอียดสินค้าที่แสดงจำนวนสต็อกจริงในคลัง ต่อไปขอส่งต่อให้กวางสาธิตการสั่งซื้อครับ"
นาทีที่ 2:30 - 4:00
3. ระบบตะกร้าสินค้าและการสั่งซื้อ (ผู้พูด: กวาง)

การกระทำ: เลือกจำนวน 2 ชิ้น กด "เพิ่มลงตะกร้า" ชี้ให้เห็นตัวเลขบน Navbar เปิดหน้า /cart ปรับจำนวนชิ้น กดไปหน้า Checkout กรอกชื่อที่อยู่ และกดยืนยันการสั่งซื้อ

"เมื่อลูกค้าสั่งซื้อ ระบบจะใช้ Database Transaction เพื่อตัดสต็อกสินค้าในคลังแบบ Real-time และบันทึกประวัติออเดอร์พร้อมราคาแบบคงที่ไว้ในระบบทันทีครับ ลำดับต่อไปขอส่งต่อให้โชคและปิงปองสาธิตระบบหลังบ้าน Admin ครับ"
นาทีที่ 4:00 - 5:30
4. ระบบหลังบ้าน Admin จัดการสินค้าและออเดอร์ (ผู้พูด: โชค & ปิงปอง)

การกระทำ: สลับไปหน้าต่าง Admin (/admin) แสดงแดชบอร์ดสถิติ โชคสาธิตสต็อกลดลงและการเพิ่มสินค้า ปิงปองเปิดเมนูคำสั่งซื้อแล้วเปลี่ยนสถานะเป็น "จัดส่งแล้ว"

"ทางฝั่งผู้ดูแลระบบ เรามีแดชบอร์ดสรุปยอดขายแบบ Real-time สามารถจัดการสินค้า อัปโหลดรูปภาพ และตรวจสอบออเดอร์ของลูกค้า พร้อมเปลี่ยนสถานะการจัดส่งได้ทันทีครับ"
นาทีที่ 5:30 - 6:30
5. ตรวจสอบผลลัพธ์ & สรุปภาพรวม (ผู้พูด: หยาง)

การกระทำ: สลับกลับมาหน้าลูกค้า รีเฟรชหน้า "คำสั่งซื้อ" แสดงสถานะเปลี่ยนเป็น "จัดส่งแล้ว" เปิดหน้า "ติดต่อเรา" และเปิด Terminal รัน php artisan test ผ่าน 40/40 tests

"จะเห็นว่าระบบหน้าบ้านและหลังบ้านทำงานสอดประสานกันแบบครบวงจร และระบบของเราผ่านการทดสอบอัตโนมัติครบ 100% กลุ่มของเราขอจบการสาธิตเพียงเท่านี้ และพร้อมตอบข้อซักถามของอาจารย์ครับ ขอบคุณครับ"
