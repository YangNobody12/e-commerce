# 📊 โครงร่างสไลด์นำเสนอผลงาน (Presentation Slides)
**โครงการ:** ระบบร้านค้าออนไลน์ (E-Commerce Web Application)  
**ทีมผู้พัฒนา:** หยาง, พลับ, โชค, กวาง, ปิงปอง  
**สถาบัน:** มหาวิทยาลัยราชภัฏเชียงใหม่  

---

### [Slide 1] หน้าปกโครงการ (Title Slide)
- **หัวข้อ:** โครงการพัฒนาระบบร้านค้าออนไลน์ (E-Commerce Web Application)
- **สโลแกน:** "ช้อปง่าย สะดวก รวดเร็ว ด้วยระบบจัดการครบวงจร"
- **สมาชิกในทีม:**
  1. **หยาง** (Team Lead / DevOps & Auth)
  2. **พลับ** (Frontend Developer)
  3. **โชค** (Product Management)
  4. **กวาง** (Cart & Order System)
  5. **ปิงปอง** (User Profile & Admin)

---

### [Slide 2] ที่มาและวัตถุประสงค์ (Motivation & Objectives)
- **ที่มา:** ธุรกิจพาณิชย์อิเล็กทรอนิกส์เติบโตอย่างรวดเร็ว ระบบที่ดีต้องมีทั้งประสบการณ์ผู้ใช้ที่ลื่นไหลและการบริหารจัดการหลังบ้านที่มีประสิทธิภาพ
- **วัตถุประสงค์:**
  1. พัฒนาระบบร้านค้าออนไลน์ที่รองรับการค้นหา กรอง และสั่งซื้อสินค้าได้สะดวก
  2. พัฒนาระบบจัดการหลังบ้านสำหรับผู้ดูแลระบบ (Admin) ในการจัดการสต็อกและออเดอร์
  3. ฝึกทักษะการทำงานร่วมกันเป็นทีมผ่าน Git Branching Strategy ในสภาพแวดล้อมเสมือนจริง

---

### [Slide 3] สถาปัตยกรรม & เทคโนโลยีที่ใช้ (Tech Stack)
- **Backend Framework:** Laravel 11 (PHP 8.2+) บนสถาปัตยกรรม MVC
- **Database:** Supabase (PostgreSQL) / SQLite Database
- **Frontend:** Blade Templates, Bootstrap 5, Bootstrap Icons, Vanilla CSS
- **Authentication:** Laravel Breeze, Bcrypt Password Hashing, CSRF Protection
- **Version Control:** Git & GitHub แยก Branch 5 คน:
  - `feature/auth`, `feature/frontend`, `feature/products`, `feature/cart-orders`, `feature/admin`

---

### [Slide 4] การออกแบบฐานข้อมูล (Database Schema & ER-Diagram)
- **6 ตารางข้อมูลหลักที่มีความสัมพันธ์กันอย่างสมบูรณ์:**
  - `users` (ผู้ใช้งาน/แอดมิน)
  - `categories` (หมวดหมู่สินค้า)
  - `products` (สินค้าและสต็อก)
  - `carts` (ตะกร้าสินค้า)
  - `orders` (คำสั่งซื้อ)
  - `order_items` (รายการสินค้าในออเดอร์)
- **การจัดการ Integrity:** กำหนด Foreign Keys, Cascade Delete และ Unique Constraints ป้องกันข้อมูลผิดพลาด

---

### [Slide 5] ฟังก์ชันหลักฝั่งลูกค้า (Customer Journey)
- **หน้าแรก & หน้าร้าน:** สินค้ามาใหม่, หมวดหมู่ยอดนิยม, แบนเนอร์โปรโมชัน
- **ระบบค้นหาและตัวกรองอัจฉริยะ:** ค้นหาตามคำ, กรองตามหมวดหมู่, กรองตามช่วงราคา, เรียงลำดับสินค้า
- **หน้ารายละเอียดสินค้า:** แสดงรูปภาพ สต็อกจริง เลือกจำนวนชิ้น และกดหยิบใส่ตะกร้า
- **ตะกร้าสินค้า (Cart):** ปรับจำนวนสินค้า คำนวณราคารวมอัตโนมัติ ลบรายการ
- **การสั่งซื้อ (Checkout):** กรอกที่อยู่จัดส่ง ยืนยันการสั่งซื้อ ตัดสต็อกสินค้าทันที
- **ติดตามสถานะ (Orders):** ติดตามสถานะออเดอร์แบบสี (รอชำระ, ดำเนินการ, จัดส่งแล้ว, สำเร็จ)

---

### [Slide 6] ฟังก์ชันหลักฝั่งผู้ดูแลระบบ (Admin Panel)
- **Admin Dashboard:** สรุปสถิติยอดขายรวม, จำนวนคำสั่งซื้อ, จำนวนสินค้า, และจำนวนสมาชิก
- **การจัดการหมวดหมู่:** เพิ่ม แก้ไข ลบหมวดหมู่สินค้า
- **การจัดการสินค้า:** เพิ่มสินค้าพร้อมอัปโหลดรูปภาพ ปรับเปลี่ยนราคา จัดการจำนวนสต็อก และเปิด/ปิดขาย
- **การจัดการคำสั่งซื้อ:** ตรวจสอบรายละเอียดออเดอร์ อัปเดตสถานะการชำระเงินและสถานะจัดส่ง
- **การจัดการผู้ใช้งาน:** ตรวจสอบรายชื่อสมาชิกและจัดการสิทธิ์ Admin

---

### [Slide 7] ไฮไลท์เชิงเทคนิคของระบบ (Technical Highlights)
- **Database Transactions (`DB::transaction`):** ป้องกันปัญหาสต็อกติดลบหรือข้อมูลไม่ตรงกันหากมีการสั่งซื้อพร้อมกัน
- **Snapshot Pricing:** บันทึกราคาและชื่อสินค้า ณ เวลาสั่งซื้อในตาราง `order_items` ป้องกันปัญหาราคาย้อนหลังเปลี่ยน
- **Thai Unicode Slug Fallback:** รองรับการสร้าง URL Slug สำหรับชื่อภาษาไทยได้อย่างสมบูรณ์
- **Automated Directory Generator:** ตรวจสอบและสร้างโฟลเดอร์สำหรับเก็บไฟล์รูปภาพอัตโนมัติ

---

### [Slide 8] การทดสอบคุณภาพระบบ (Quality Assurance)
- พัฒนาชุด Automated Testing ด้วย **PHPUnit / Pest**
- **ผลการทดสอบ: ผ่าน 100% ครบทั้ง 40 Tests (110 Assertions)**
  - ทดสอบระบบสมัครสมาชิก ล็อกอิน และโปรไฟล์
  - ทดสอบหน้าร้าน ค้นหา กรองหมวดหมู่
  - ทดสอบระบบตะกร้าสินค้า การ Checkout และการตัดสต็อก
  - ทดสอบระบบ Admin การจัดการสินค้าและอัปเดตออเดอร์

---

### [Slide 9] การสาธิตการทำงานจริง (Live Demo Overview)
- สาธิตการใช้งานจริงจาก 2 มุมมอง (ลูกค้า vs ผู้ดูแลระบบ):
  1. การเลือกสินค้า ค้นหา และหยิบใส่ตะกร้า
  2. การสั่งซื้อสินค้าและตัดสต็อกสินค้าในคลัง
  3. แอดมินตรวจสอบออเดอร์และเปลี่ยนสถานะการจัดส่ง
  4. ลูกค้าตรวจเช็คการอัปเดตสถานะแบบ Real-time
