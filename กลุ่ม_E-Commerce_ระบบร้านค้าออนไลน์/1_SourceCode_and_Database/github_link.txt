================================================================================
โครงการ: ระบบร้านค้าออนไลน์ (E-Commerce Web Application)
GitHub Repository & Source Code Details
================================================================================

GitHub Repository URL:
https://github.com/YangNobody12/e-commerce

Branches:
- main: Branch หลักสำหรับ Deploy และส่งงาน (มีโค้ดสมบูรณ์และผ่านการทดสอบ 100%)
- develop: Branch รวมงานของทีมเพื่อทดสอบก่อนเข้า main
- feature/auth: งานระบบล็อกอินและโครงสร้างระบบ (หยาง)
- feature/frontend: งานหน้าบ้าน หน้าร้าน และสินค้า (พลับ)
- feature/products: งานจัดการสินค้าและหมวดหมู่หลังบ้าน (โชค)
- feature/cart-orders: งานตะกร้าสินค้าและการสั่งซื้อ (กวาง)
- feature/admin: งานโปรไฟล์ผู้ใช้และแดชบอร์ดแอดมิน (ปิงปอง)

ขั้นตอนการติดตั้งจาก Source Code หรือ Git Clone:
1. git clone https://github.com/YangNobody12/e-commerce.git
2. cd e-commerce
3. composer install
4. cp .env.example .env
5. php artisan key:generate
6. php artisan migrate --seed (หรือนำเข้า database.sql)
7. php artisan serve
