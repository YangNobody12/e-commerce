# 📖 คู่มือการใช้งานโปรแกรมโดยสังเขป (User Manual)
**โครงการ:** ระบบร้านค้าออนไลน์ (E-Commerce Web Application)  
**URL ตัวอย่างในการทดสอบ:** `http://127.0.0.1:8000`

---

## 1. ข้อมูลเริ่มต้นและบัญชีทดสอบ (Test Accounts)

### 1.1 การเริ่มใช้งานระบบ
1. ตรวจสอบว่าโปรแกรมกำลังทำงานอยู่ที่ `http://127.0.0.1:8000` (รันคำสั่ง `php artisan serve`)
2. เปิดเว็บบราวเซอร์ เช่น Google Chrome, Safari, หรือ Edge แล้วไปที่ `http://127.0.0.1:8000`

### 1.2 ข้อมูลบัญชีสำหรับทดสอบระบบ
| บทบาท (Role) | อีเมล (Email) | รหัสผ่าน (Password) | สิทธิ์การเข้าถึง |
|---|---|---|---|
| **ผู้ดูแลระบบ (Admin)** | `admin@example.com` | `password` | เข้าถึงหน้าบ้านและระบบหลังบ้าน (`/admin`) ได้ทั้งหมด |
| **ลูกค้าทั่วไป (User)** | `user@example.com` | `password` | สั่งซื้อสินค้า, ตะกร้าสินค้า, ประวัติคำสั่งซื้อ, โปรไฟล์ |
| **หรือสมัครใหม่** | ผ่านเมนู "สมัครสมาชิก" | กำหนดเอง (อย่างน้อย 8 ตัวอักษร) | ได้รับสิทธิ์เป็น User ทันที |

## 2. คู่มือสำหรับลูกค้า / ผู้ใช้งานทั่วไป (Customer Guide)

### 2.1 หน้าแรก (Home)
- เข้าที่ URL `/`
- แสดงแบนเนอร์แนะนำร้านค้า, เมนูนำทางด้านบน (Navbar)
- แสดงแถบหมวดหมู่สินค้าพร้อมระบุจำนวนสินค้าในแต่ละหมวด
- แสดงรายการสินค้ามาใหม่ 8 รายการ พร้อมปุ่ม "หยิบใส่ตะกร้า" ได้ทันที

### 2.2 การค้นหาและเลือกชมสินค้า (Shop & Filter)
- คลิกเมนู **"สินค้า"** ที่แถบด้านบน (URL `/shop`)
- **ค้นหาตามชื่อสินค้า (Search):** พิมพ์คำค้นหาในช่องค้นหาแล้วกดปุ่ม "ค้นหา"
- **กรองตามหมวดหมู่:** เลือกหมวดหมู่ที่ต้องการจากเมนูด้านข้าง เช่น เสื้อผ้า, เครื่องใช้ในบ้าน, อิเล็กทรอนิกส์
- **กรองตามช่วงราคา:** ระบุราคาต่ำสุดและราคาสูงสุดที่ต้องการ
- **เรียงลำดับสินค้า (Sorting):** เลือกเรียงตาม "ล่าสุด", "ราคา: ต่ำ - สูง", "ราคา: สูง - ต่ำ", หรือ "ชื่อ ก-ฮ"
- ระบบแบ่งหน้า (Pagination) แสดงผลหน้าละ 12 รายการ

### 2.3 การดูรายละเอียดสินค้า (Product Detail)
- คลิกที่รูปภาพหรือชื่อสินค้าจากหน้ารายการสินค้า
- แสดงรูปภาพขนาดใหญ่, ชื่อสินค้า, ป้ายหมวดหมู่, ราคา, สถานะสินค้าในคลัง
- สามารถกดปุ่มบวก/ลบ เพื่อระบุ **จำนวนชิ้นที่ต้องการสั่งซื้อ**
- กดปุ่ม **"เพิ่มลงตะกร้า"** เพื่อบรรจุสินค้าลงในตะกร้าสินค้า

### 2.4 การจัดการตะกร้าสินค้า (Cart Management)
- คลิกที่ไอคอน **"ตะกร้า"** บนแถบนำทาง (มีตัวเลขสีแดงแสดงจำนวนสินค้าคงอยู่ในตะกร้า)
- แสดงรายการสินค้าทั้งหมดที่เลือกไว้, ราคาต่อหน่วย, ยอดรวมย่อย, และยอดรวมสุทธิ
- **แก้ไขจำนวน:** เปลี่ยนตัวเลขจำนวนชิ้นแล้วกดปุ่มอัปเดต (ไอคอนบันทึก)
- **ลบรายการ:** กดปุ่มถังขยะสีแดงเพื่อลบสินค้าชิ้นนั้นออกจากตะกร้า
- กดปุ่ม **"ไปหน้าสั่งซื้อสินค้า"** เพื่อดำเนินการชำระเงิน

### 2.5 การสั่งซื้อสินค้าและการชำระเงิน (Checkout)
- ตรวจสอบรายการสรุปสินค้าและยอดรวมเงินที่ต้องชำระ
- กรอกข้อมูลจัดส่ง:
  - ชื่อ-นามสกุล ผู้รับพัสดุ
  - เบอร์โทรศัพท์ติดต่อ
  - ที่อยู่จัดส่งพัสดุอย่างละเอียด
  - หมายเหตุเพิ่มเติม (ถ้ามี)
- กดปุ่ม **"ยืนยันการสั่งซื้อ"** ระบบจะทำการ:
  1. บันทึกคำสั่งซื้อลงฐานข้อมูล
  2. สร้างรหัสคำสั่งซื้ออัตโนมัติ (เช่น `ORD-20260922-XXXX`)
  3. ตัดสต็อกสินค้าในคลังแบบ Real-time
  4. เคลียร์ตะกร้าสินค้า
  5. นำทางไปยังหน้ารายละเอียดคำสั่งซื้อ พร้อมข้อความแจ้งความสำเร็จ

### 2.6 การตรวจสอบประวัติและสถานะคำสั่งซื้อ (Order History)
- คลิกที่ชื่อผู้ใช้ด้านบนขวา ➔ เลือก **"คำสั่งซื้อ"** (URL `/orders`)
- แสดงตารางรายการคำสั่งซื้อทั้งหมดของตนเอง, วันที่สั่ง, ยอดรวมเงิน, และสถานะปัจจุบัน
- สถานะคำสั่งซื้อแบ่งตามสีเพื่อความชัดเจน:
  - <span class="badge bg-warning text-dark">รอชำระเงิน / รอดำเนินการ (Pending)</span>
  - <span class="badge bg-info text-dark">กำลังดำเนินการ (Processing)</span>
  - <span class="badge bg-primary">จัดส่งแล้ว (Shipped)</span>
  - <span class="badge bg-success">สำเร็จ / ได้รับสินค้าแล้ว (Delivered)</span>
  - <span class="badge bg-danger">ยกเลิก (Cancelled)</span>
- สามารถกดปุ่ม **"ดูรายละเอียด"** เพื่อดูรายการสินค้าในออเดอร์นั้นๆ ได้

### 2.7 การจัดการโปรไฟล์ส่วนตัว (Profile Management)
- คลิกที่ชื่อผู้ใช้ ➔ เลือก **"โปรไฟล์"** (URL `/profile`)
- ดูข้อมูลส่วนตัว: ชื่อ, อีเมล, เบอร์โทร, ที่อยู่, วันที่สมัครสมาชิก
- กดปุ่ม **"แก้ไขโปรไฟล์"** เพื่ออัปเดตเบอร์โทรและที่อยู่จัดส่งเริ่มต้น
- กดปุ่ม **"เปลี่ยนรหัสผ่าน"** เพื่อตั้งรหัสผ่านใหม่ได้อย่างปลอดภัย

### 2.8 การติดต่อทีมงาน (Contact Us)
- คลิกเมนู **"ติดต่อเรา"** บน Navbar หรือคลิกที่ลิงก์ใน Footer ด้านล่าง
- ดูรายชื่อทีมงานผู้พัฒนา 5 คน พร้อมบทบาทหน้าที่
- ดูข้อมูลการติดต่อ ที่ตั้ง มหาวิทยาลัยราชภัฏเชียงใหม่, อีเมล, เบอร์โทร, เวลาทำการ
- สามารถพิมพ์ข้อความในแบบฟอร์มแล้วกด "ส่งข้อความ" เพื่อติดต่อทีมงาน

## 3. คู่มือสำหรับผู้ดูแลระบบ (Admin Guide)

### 3.1 การเข้าสู่ระบบ Admin
1. เข้าสู่ระบบด้วยบัญชี Admin (`admin@example.com` / `password`)
2. ระบบจะพามุ่งตรงไปยังหน้า **Admin Dashboard** (`/admin`) โดยอัตโนมัติ
3. เมนูด้านบนจะมีปุ่มลัด **"Admin Panel"** สีแดงเด่นชัด

### 3.2 หน้าควบคุมหลัก (Admin Dashboard)
- แสดงกล่องสถิติภาพรวมธุรกิจแบบ Real-time 4 ด้าน:
  1. **ยอดขายรวม (Total Revenue):** คำนวณจากออเดอร์ที่สถานะสำเร็จ
  2. **คำสั่งซื้อทั้งหมด (Total Orders):** จำนวนออเดอร์ในระบบ
  3. **สินค้าทั้งหมด (Total Products):** จำนวนรายการสินค้าที่มีในระบบ
  4. **สมาชิกลูกค้า (Total Users):** จำนวนผู้ใช้งานในระบบ
- แสดงตาราง **คำสั่งซื้อล่าสุด (Recent Orders)** 5 รายการ พร้อมปุ่มจัดการด่วน

### 3.3 การจัดการหมวดหมู่สินค้า (Categories Management)
- ไปที่เมนู **"จัดการหมวดหมู่"** (`/admin/categories`)
- **เพิ่มหมวดหมู่ใหม่:** กดปุ่ม "+ เพิ่มหมวดหมู่" ➔ กรอกชื่อหมวดหมู่, คำอธิบาย และอัปโหลดรูปภาพ ➔ กดบันทึก (ระบบสร้าง URL Slug อัตโนมัติ รองรับภาษาไทย)
- **แก้ไขหมวดหมู่:** กดปุ่ม "แก้ไข" เพื่อเปลี่ยนชื่อ รูปภาพ หรือคำอธิบาย
- **ลบหมวดหมู่:** กดปุ่ม "ลบ" พร้อมมีกล่องยืนยันป้องกันการกดผิดพลาด

### 3.4 การจัดการสินค้า (Products Management)
- ไปที่เมนู **"จัดการสินค้า"** (`/admin/products`)
- **เพิ่มสินค้าใหม่:** กดปุ่ม "+ เพิ่มสินค้า" ➔ เลือกหมวดหมู่ ➔ กรอกชื่อสินค้า, ราคา, จำนวนสต็อก, รายละเอียด ➔ อัปโหลดรูปภาพ ➔ กำหนดสถานะเปิดขาย ➔ กดบันทึก
- **แก้ไขสินค้า:** สามารถอัปเดตราคา สต็อก หรือเปลี่ยนรูปภาพได้ตลอดเวลา
- **สลับสถานะเปิด/ปิดขาย:** สามารถปิดการขายชั่วคราวได้โดยสินค้าจะไม่แสดงที่หน้าร้าน
- **ลบสินค้า:** ลบสินค้าที่ยกเลิกการจำหน่ายออกจากระบบ

### 3.5 การจัดการคำสั่งซื้อ (Orders Management)
- ไปที่เมนู **"จัดการคำสั่งซื้อ"** (`/admin/orders`)
- แสดงรายการคำสั่งซื้อของลูกค้าทั้งหมดในระบบ เรียงจากล่าสุดไปเก่าสุด
- แสดงรหัสออเดอร์, ชื่อลูกค้า, วันที่สั่งซื้อ, ยอดรวมเงิน, และสถานะปัจจุบัน
- คลิก **"ดูรายละเอียด"** เพื่อตรวจสอบรายการสินค้าที่ลูกค้าสั่ง, ที่อยู่จัดส่ง, และเบอร์โทรติดต่อ
- **อัปเดตสถานะคำสั่งซื้อ:** ในหน้ารายละเอียดออเดอร์ ผู้ดูแลระบบสามารถเปลี่ยนสถานะได้จาก Dropdown:
  - *รอชำระเงิน (Pending)*
  - *กำลังดำเนินการ (Processing)*
  - *จัดส่งแล้ว (Shipped)*
  - *สำเร็จแล้ว (Delivered)*
  - *ยกเลิกคำสั่งซื้อ (Cancelled)*
  - แล้วกดปุ่ม **"อัปเดตสถานะ"** เพื่อบันทึกทันที ลูกค้าจะเห็นสถานะอัปเดตที่หน้าประวัติของตนเองทันที

### 3.6 การจัดการผู้ใช้งาน (Users Management)
- ไปที่เมนู **"จัดการผู้ใช้"** (`/admin/users`)
- แสดงรายชื่อสมาชิกทั้งหมดในระบบ พร้อมระบุ Role (`Admin` หรือ `User`)
- สามารถกดแก้ไขข้อมูล หรือปรับสิทธิ์สมาชิกจาก User ทั่วไปให้เป็น Admin ได้

## 4. สรุปความปลอดภัยและมาตรฐานของระบบ
- รหัสผ่านทุกบัญชีผ่านการ Hash ด้วยมาตรฐาน **Bcrypt**
- ป้องกันการโจมตีแบบ **CSRF (Cross-Site Request Forgery)** ทุกฟอร์ม
- มี **Middleware Authenticated & Admin Protection** ป้องกันไม่ให้บุคคลภายนอกเข้าถึงระบบจัดการหลังบ้าน
- ใช้ **Database Transactions** ในการตัดสต็อกสินค้า ป้องกันปัญหาสต็อกติดลบหรือข้อมูลคลาดเคลื่อนเมื่อมีผู้สั่งซื้อพร้อมกัน
