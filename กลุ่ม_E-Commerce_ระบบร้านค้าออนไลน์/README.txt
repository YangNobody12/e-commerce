--------------------------------------------------------------------------------
วิธีติดตั้งและรันโปรแกรมจาก Source Code:
--------------------------------------------------------------------------------
1. แตกไฟล์ zip: e-commerce-sourcecode.zip
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์
3. ติดตั้ง Dependencies: composer install
4. คัดลอกไฟล์ Environment: cp .env.example .env
5. สร้าง Application Key: php artisan key:generate
6. สร้างฐานข้อมูลและนำเข้าข้อมูล: php artisan migrate --seed (หรือนำเข้า database.sql)
7. เริ่มรันเซิร์ฟเวอร์: php artisan serve
8. เปิดบราวเซอร์ไปที่: http://127.0.0.1:8000
